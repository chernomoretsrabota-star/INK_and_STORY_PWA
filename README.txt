INK & STORY — установка

В папке находятся файлы PWA-приложения.

ВАЖНО: чтобы установить приложение на главный экран и включить офлайн-режим, размести папку на HTTPS-хостинге (например, GitHub Pages или Netlify). Не открывай index.html как обычный файл, если хочешь именно установку PWA.

GitHub Pages:
1. Создай новый репозиторий на GitHub.
2. Загрузи ВСЕ файлы из этой папки в корень репозитория.
3. В Settings → Pages выбери Deploy from a branch, ветка main, папка /(root).
4. Дождись появления HTTPS-ссылки.
5. Открой ссылку на телефоне.

Android (Chrome): меню ⋮ → Установить приложение / Добавить на главный экран.
iPhone (Safari): Поделиться → На экран «Домой» → Добавить.

Сохранение: автоматически в локальном хранилище браузера на этом устройстве. Регулярно используй «Экспорт всех проектов» для резервной копии. Очистка данных браузера может удалить проекты. Для переноса на другой телефон экспортируй резервную копию и импортируй её там.

Возможности: несколько проектов, обложки, паспорт книги, аннотация, логлайн, синопсис, редактор рукописи с форматированием и картинками, главы, заметки, анкеты персонажей с фото, лор мира, подсчёт слов, экспорт/импорт JSON, автосохранение.
